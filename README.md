# rvt-jobs-sons

Efeitos sonoros dos empregos do `rvt_jobs` (servidor Neon, FiveM). São gravações reais do freesound.org, todas em
Creative Commons 0 (domínio público): só cortadas, normalizadas e com fade. Créditos em `CREDITOS.txt`.

O jogo lê `catalog.json` e os `.ogg` pelo jsDelivr (`https://cdn.jsdelivr.net/gh/<dono>/rvt-jobs-sons@<tag>/`), então os
sons não entram no download da cidade. Ao mudar sons, crie uma tag nova e troque a versão em `Config.SfxBase`.

Os scripts que cortam os sons ficam fora deste repositório (`Projetos/FiveM/Assets/rvt-jobs-sons/scripts`).
